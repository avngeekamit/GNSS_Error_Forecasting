# Dataset

This directory contains the GNSS data used for the Day-6 forecasting
experiments in this research repository.

## Files

### GEO_day6_train.csv

This file contains the GNSS observations used for model training and
forecast generation.

The data contains the GNSS error variables used by the forecasting
models:

- `x_error` — X-axis ephemeris error
- `y_error` — Y-axis ephemeris error
- `z_error` — Z-axis ephemeris error
- `satclockerror` — Satellite clock error

The temporal information is represented by the `utc_time` index.

---

### GEO_day6_actual.csv

This file contains the actual GNSS observations for Day 6.

It is used as the ground-truth dataset for evaluating the forecasts
generated by:

- Hybrid XGBoost
- Direct GRU
- Direct LSTM

The Day-6 dataset contains **95 observations** sampled at **15-minute
intervals**, covering:
